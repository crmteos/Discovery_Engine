## 1. Context & Objective
With `schema_validator.py`, `intake_processor.py`, and `bus_inspector.py` fully deployed and verified with `exit_code: 0`, **Step 2** of the roadmap requires building local **Media Extractors** under `05_Knowledge_Aggregator/media_extractors/`.

This engine will automatically inspect raw media files (images and video metadata) deposited in `Intake_Queue/` and generate schema-compliant `image_metadata` and `video_index` JSON drafts (W3C PROV-O and SKOS compliant) ready for ingestion into the message bus.

---

## 2. Deliverables & Execution Requirements

### Task 1: Create `05_Knowledge_Aggregator/media_extractors/image_extractor.py`
* **Functionality:** 
  * Ingest raw image files (PNG, JPG, WEBP, SVG) from `Intake_Queue/media/images/`.
  * Extract metadata: resolution (width/height), format, file size, SHA256 checksum.
  * Generate a fully compliant `image_metadata` JSON envelope according to `image_metadata_template.json`.
  * Ensure mandatory W3C PROV-O fields (`prov:wasAttributedTo: "aggregator.architect"`, `prov:generatedAtTime`, `prov:hadPrimarySource`, `confidence_score`) and SKOS fields (`skos:broader`, `skos:narrower`, `skos:related`).
  * Verify output via `schema_validator.py` returning `exit_code: 0`.

### Task 2: Create `05_Knowledge_Aggregator/media_extractors/video_extractor.py`
* **Functionality:**
  * Ingest video metadata / video files (MP4, MKV, AVI, or synthetic metadata stubs) from `Intake_Queue/media/videos/`.
  * Extract/parse duration, frame rate, resolution, codec metadata, and SHA256 checksum.
  * Generate temporal chunks stubs with timestamps (`timestamp_start`, `timestamp_end`), transcript placeholders, and visual key markers.
  * Generate a fully compliant `video_index` JSON envelope according to `video_index_template.json`.
  * Verify output via `schema_validator.py` returning `exit_code: 0`.

### Task 3: E2E Smoke Test & Verification
* Create test sample files/stubs in `Intake_Queue/media/`.
* Run both extractors and pipe generated JSON drafts into `schema_validator.py` and `intake_processor.py`.
* Ensure records are successfully logged into `Bridge/messages.jsonl` via `bus_manager.py`.
* Run `bus_inspector.py` to confirm 100% bus validity (`0` errors).

### Task 4: Generate Execution Report
* Save detailed summary report to:
  `Bridge/out/aggregator_reports/report_media_extractors_[TIMESTAMP].md`
* Include test results for both extractors, schema validation exit codes, and bus inspector status.
