### Step 2 — Create Helper Scripts in `06_Formalized_Model/src/`

#### 1. `06_Formalized_Model/src/model_bus_listener.py`
A Python script that:
- Connects to `Bridge/messages.jsonl`.
- Filters messages targeted to `model.builder` or `receiver: "model.builder"`.
- Provides CLI methods to query pending tasks, display incoming Core hypotheses (`HYPOTHESIS_*`), and send response messages back to the bus.

#### 2. `06_Formalized_Model/src/model_assembler.py`
A Python script that:
- Reads proven graph invariants and TDA hypothesis reports generated by `01_Formal_Core`.
- Assembles them into an ISO/IEC/IEEE 42010 compliant three-view JSON object:
  - **Structural View:** Graph nodes, edges, entity relationships.
  - **Behavioral View:** Input/output state transitions & message flows.
  - **Parametric View:** Mathematical invariants & SymPy constraints.

#### 3. `06_Formalized_Model/src/owl_export_validator.py`
A Python script that:
- Validates the assembled model against W3C OWL 2 DL logical consistency rules (using `rdflib` or local SymPy/NetworkX logical checks).
- Ensures no logical contradictions exist in the synthesized ontology.

#### 4. `06_Formalized_Model/src/openapi_exporter.py`
A Python script that:
- Translates the assembled model into machine-readable export formats:
  - **OpenAPI 3.1** specification (`.json` / `.yaml`) for external REST API endpoints.
  - **JSON-LD 1.1** context for semantic web interoperability.
